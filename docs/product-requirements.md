# プロダクト要求定義書: 撮影用インスタ画面メーカー

## 1. プロダクトビジョンと目的

映画・演劇・映像制作の撮影現場において、俳優が操作する「SNS画面」を撮影用の小道具として即座に用意できるアプリを提供する。

実際のInstagramアプリを使うと、本物のユーザー情報や投稿が映り込む、通信が発生する、著作権・肖像権上の問題が生じる、といった撮影上の障害がある。本アプリは、Instagram風のUIを模したダミー画面(投稿詳細・プロフィール・フィード・ストーリーズなど)を自由に作成し、端末の画面をそのまま撮影素材として使えるようにすることで、これらの障害を取り除く。

本プロダクトは「撮影用フェイク画面メーカー」シリーズの第3弾であり、既存の「撮影用トーク画面メーカー(LINE版)」「撮影用ポスト画面メーカー(X版)」に続く、Instagram版として位置づける。既存シリーズとはコード・データ共有を行わず、独立したアプリとして開発する。

## 2. ターゲットユーザーと課題・ニーズ

### ターゲットユーザー
- 映画・自主制作映像・演劇・学生映像作品などの制作スタッフ(小道具・美術担当、監督、助監督など)
- 映像制作を学ぶ学生
- 個人でショート動画・SNS用コンテンツを制作するクリエイター

### 課題
- 撮影シーンで「SNS画面を操作している」演技をさせたいが、実際のSNSアプリでは本物の投稿・個人情報が映り込んでしまう
- 実際のSNSアプリは通信環境やアカウント状態に撮影が左右される(圏外、ログアウト状態など)
- 架空の投稿内容・コメント・ユーザー名を用意する手段がなく、撮影のたびに手作業で偽画面を作る(モックアップをスクリーンショットするなど)コストが高い
- 低予算の学生・自主制作の現場では、専用ツールに費用をかけられない

### ニーズ
- 任意のテキスト・画像・ユーザー名を差し込んだ「本物そっくりのInstagram画面」を、端末単体・オフラインで素早く作成したい
- 投稿詳細だけでなく、フィードやプロフィール、ストーリーズなど、シーンに応じた複数の画面パターンが欲しい
- 無料で、かつ透かし(ウォーターマーク)なしで使いたい

## 3. 主要な機能一覧(Phase 1)

1. 投稿詳細画面(投稿画像/テキスト、いいね数・いいねトグル、コメント一覧・入力欄、ユーザー情報・投稿時間)
2. プロフィール画面(プロフィール画像・ユーザー名・自己紹介文、投稿数/フォロワー数/フォロー数、投稿サムネイルのグリッド表示)
3. フォロワー一覧 / フォロー一覧画面(ユーザーアイコン・ユーザー名のリスト)
4. フィード(タイムライン)画面(複数投稿のスクロール一覧、いいね/コメント/シェアアイコン、ストーリーズ用アイコン列)
5. ストーリーズ画面(全画面表示・タップで次送り、進捗バー、ユーザーアイコン・ユーザー名)

Phase 2以降の候補機能(優先度未定): プロフィール詳細機能拡張、DM画面、動画対応。詳細は本書「8. スコープ外・将来検討事項」を参照。

## 4. 成功の定義

- 撮影現場のスタッフが、初見でも迷わず「投稿画面」「プロフィール」「フィード」「ストーリーズ」を数分以内に作成し、スクリーンショットとして撮影に使える状態にできること
- コア機能(Phase 1の全画面)が完全無料・ウォーターマードなしで利用できること
- オフライン環境(通信なし)でも全機能が問題なく動作すること
- iOS / Android の両OSで同等の見た目・操作性が得られること

## 5. ビジネス要件

- **収益モデル**: フリーミアム。コア機能(Phase 1で定義する全画面)は完全無料・ウォーターマークなしで提供する。
- **有料機能**: 追加機能を一回購入(買い切り)で提供する想定。ただし、Phase 1時点では有料機能の具体的な内容は未定とし、価格設定よりも対象ユーザー(制作現場のスタッフ・学生など)へのアクセシビリティを優先する方針を維持する。有料機能の具体案は本書の対象外とし、`functional-design.md`以降、または将来のPhaseで別途検討する。
- **対象プラットフォーム**: iOS / Android 両対応。
- **既存シリーズとの関係**: 「撮影用トーク画面メーカー(LINE版)」「撮影用ポスト画面メーカー(X版)」とはコード・データベースを共有せず、完全に独立したアプリとして開発・提供する。

## 6. ユーザーストーリー

1. 制作スタッフとして、俳優に「誰かの投稿にいいねしてコメントする」演技をさせたいので、任意の投稿画像・ユーザー名・コメントを入力した投稿詳細画面を作り、俳優の端末に表示させたい。
2. 助監督として、撮影シーンで「友人のプロフィールを見ている」場面を撮りたいので、架空のプロフィール画像・自己紹介・投稿数などを設定したプロフィール画面を用意したい。
3. 監督として、「SNSを眺めながらスクロールする」芝居を自然に見せたいので、複数の架空投稿が並ぶフィード画面を作成し、実際にスクロールできる状態で撮影したい。
4. 制作スタッフとして、「友人一覧を見ている」シーンのために、フォロワー/フォロー一覧画面に架空のユーザーリストを表示したい。
5. 制作スタッフとして、「誰かのストーリーズを見ている」演技のために、全画面のストーリーズ画面を進捗バー付きで表示・タップ送りできるようにしたい。
6. 学生クリエイターとして、予算をかけずに撮影素材を用意したいので、追加費用なしでコア機能をすべて使いたい。

## 7. 受け入れ条件

- 投稿詳細画面で、いいねアイコンをタップすると、いいね数が増減しトグル状態が視覚的に切り替わること
- 投稿詳細画面で、コメント入力欄からコメントを追加すると、コメント一覧に即座に反映されること
- プロフィール画面で、投稿数/フォロワー数/フォロー数の各項目をタップすると、対応する一覧画面(投稿グリッド/フォロワー一覧/フォロー一覧)に遷移すること
- フィード画面で、複数の投稿をスクロールして閲覧でき、各投稿にいいね/コメント/シェアアイコンが表示されること
- フィード画面のストーリーズ用アイコン列をタップすると、該当ユーザーのストーリーズ画面に遷移すること
- ストーリーズ画面で、画面タップにより次のストーリーへ送られ、進捗バーが表示中のストーリーに応じて更新されること
- すべての画面が通信を必要とせず、オフライン環境で動作すること
- 入力したテキスト・画像・ユーザー名などがローカルに保存され、アプリ再起動後も保持されること
- Phase 1で定義した全機能に、課金なしでウォーターマークなしにアクセスできること

## 8. 機能要件

- ユーザーは、投稿画像(端末から選択)・投稿テキスト・ユーザー名・アイコン画像・投稿時間を自由に設定し、投稿詳細画面を生成できる
- ユーザーは、いいね数を手動で設定でき、画面上のいいねアイコンをタップしてトグル(オン/オフ)できる
- ユーザーは、コメント(ユーザー名+本文)を複数件登録・編集・削除でき、コメント一覧に表示できる
- ユーザーは、プロフィール画像・ユーザー名・自己紹介文・投稿数/フォロワー数/フォロー数を設定し、プロフィール画面を生成できる
- ユーザーは、プロフィール画面に投稿サムネイルをグリッド表示で複数登録できる
- ユーザーは、フォロワー一覧・フォロー一覧用のユーザー(アイコン+ユーザー名)を複数登録し、一覧画面として表示できる
- ユーザーは、複数の投稿を組み合わせてフィード(タイムライン)画面を構成し、スクロール表示できる
- ユーザーは、フィード上にストーリーズ用アイコン(ユーザーごと)を配置し、タップでストーリーズ画面へ遷移できる
- ユーザーは、ストーリーズ画面において、1ユーザーあたり複数枚の画像を登録し、タップ操作で次のストーリーへ送ることができる。進捗バーはストーリー枚数・表示位置に応じて表示される
- 作成した画面の設定内容(投稿・プロフィール・フォロワー等のデータ)は端末内にローカル保存され、次回起動時も再利用できる

## 9. 非機能要件

- **プラットフォーム**: iOS / Android のネイティブアプリとして提供する(Flutterによるクロスプラットフォーム開発)
- **オフライン動作**: 通信機能を持たず、全機能がオフラインで完結する。実際のSNSサーバーとの通信は一切行わない
- **データ保存**: 入力データは端末内のローカルDBに保存する。外部サーバーへの送信は行わない
- **ダークモード**: Phase 1では非対応とする。ライトモードのみを提供する
- **パフォーマンス**: 画面遷移・スクロール・画像表示は撮影現場での実演操作に耐える応答速度(体感で遅延を感じさせない程度)を確保する
- **見た目の再現度**: 実際のInstagramアプリに近いUI・配色・アイコンを再現し、撮影素材として違和感のない見た目を実現する
- **プライバシー・セキュリティ**: ユーザーが入力する画像・テキストは端末内にのみ保存し、外部送信・解析は行わない。実在の個人情報を収集する機能は持たない

## 10. スコープ外・将来検討事項

### Phase 1のスコープ外
- 動画対応(投稿・フィード・ストーリーズでの動画再生、サムネイル生成など)は静止画のみとし、対象外とする
- 実際のSNSへの投稿・通信機能は持たない
- アカウント作成・ログイン機能は持たない
- 他ユーザーとのリアルタイム連携機能は持たない
- ダークモード対応は行わない

### Phase 2以降の候補(優先度未定)
- プロフィール詳細機能の拡張
- DM画面(1対1トーク一覧+個別チャット。LINE版のトーク画面に近いUIをInstagram風にアレンジ)
- 動画対応(投稿・フィード・ストーリーズでの動画再生、サムネイル生成など)
- 有料機能(買い切り課金)の具体的な内容の検討

### 未確定事項
- Phase 2以降の優先順位
- 有料機能の具体的な内容・価格
