# PRD: 撮影用インスタ画面メーカー

## 1. 概要

映画・演劇の撮影現場向け「フェイク画面メーカー」シリーズの第3弾。Instagram風のUIを模したダミー画面(投稿詳細・プロフィール・フィード)を作成し、撮影用の小道具として使えるスクリーンショットを生成するアプリ。

- シリーズ既存: 撮影用トーク画面メーカー(LINE版)、撮影用ポスト画面メーカー(X版)
- 今回: Instagram版

## 2. 対象プラットフォーム

- iOS / Android 両対応

## 3. 収益モデル

- フリーミアム
- コア機能は完全無料・ウォーターマークなし
- 追加機能は有料一回購入(買い切り)
- 方針: 価格設定よりも対象ユーザー(制作現場のスタッフ・学生など)へのアクセシビリティを優先

## 4. 技術構成

- Flutter / Dart
- 状態管理: Riverpod
- ローカルDB: Hive
- 開発: Claude Code(devcontainer環境)
- PRD配置: `/docs/ideas/`、開発ルールは`CLAUDE.md`で管理

## 5. スコープ(フェーズ)

### Phase 1(今回)
1. **投稿詳細画面**
   - 投稿画像/テキスト表示
   - いいね数・いいねアイコン(押下トグル)
   - コメント一覧表示・コメント入力欄
   - ユーザー名・アイコン・投稿時間
2. **プロフィール画面**
   - プロフィール画像・ユーザー名・自己紹介文
   - 投稿数/フォロワー数/フォロー数(タップでそれぞれの一覧画面へ遷移)
   - 投稿サムネイル一覧(グリッド表示)
3. **フォロワー一覧 / フォロー一覧画面**
   - ユーザーアイコン・ユーザー名のリスト表示
   - プロフィール画面から「フォロワー数」「フォロー数」タップで遷移
4. **フィード(タイムライン)画面**
   - 複数投稿のスクロール一覧
   - 各投稿にいいね/コメント/シェアアイコン
   - ストーリーズ用アイコン列(タップでストーリーズ画面へ遷移)
5. **ストーリーズ画面**
   - 全画面表示・タップで次へ送り
   - 進捗バー(複数ストーリー分)
   - ユーザーアイコン・ユーザー名表示

### Phase 2以降(候補・優先度未定)
- プロフィール詳細機能拡張
- DM画面(1対1トーク一覧+個別チャット、LINE版のトーク画面に近いUIをInstagram風に)
- 動画対応(投稿・フィード・ストーリーズでの動画再生、サムネイル生成など)

## 6. 非対象(スコープ外)

- Phase 1では動画対応なし(静止画のみ)
- 実際のSNS投稿・通信機能
- アカウント作成・ログイン機能
- 他ユーザーとのリアルタイム連携

## 7. 未確定事項

- ダークモード対応の要否
